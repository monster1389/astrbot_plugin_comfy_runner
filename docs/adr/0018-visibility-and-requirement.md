# 可见性与必填性是两个独立维度

契约里的每个参数各自声明 `visible` 与 `required`：`visible` 决定这个参数是否进入模型能看到的
接口，`required` 决定模型看得见时是否必须提供。隐藏参数照旧参与映射与约束校验，只是模型看不见、
也传不进来。

分成两个字段而不是「删掉映射就当没这个参数」的原因：契约因此成为工作流可控面的完整清单。
想临时收回或放开某个参数，只改一个布尔值，不用重写映射；`/comfy check` 也还能继续核对它是否
仍然指向存在的节点与字段。代价是隐藏参数会腐烂，所以检查命令点名列出它们。

`visible: false` 与 `required: true` 不能同时成立：模型给不出值，这个组合只会让每次调用都失败，
因此在加载阶段就当作契约错误。

## 后果

- `comfy_inspect` 只展示可见参数，参数 Schema 也只为可见参数生成，隐藏参数传进来按「未声明参数」拒绝。
- `/comfy check` 报出每个契约的参数总数、对外数量，并单独列出隐藏参数名。
- 隐藏参数的值只能来自工作流文件本身，改它就等于改工作流。
