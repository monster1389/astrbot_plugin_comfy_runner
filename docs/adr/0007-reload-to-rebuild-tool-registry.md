# 重载插件时整体重建工具注册

插件启动或重载时读取契约，校验整个启用集合，再用 `FunctionTool` 和显式 JSON Schema 重建工具注册；运行期间不监听契约文件，也不增量增删工具。契约修改只有经过明确的插件重载才生效，从而避免重复注册、旧 Schema 残留和读取到未完成修改。

## 后果

- 不使用依赖 docstring 生成参数的工具装饰器表达动态契约。
- 任一启用契约存在 JSON、工具名唯一性、必填字段或映射错误，整个插件拒绝完成加载并指出文件与原因；不跳过错误契约后降级提供其他工具。
- 禁用契约不注册为工具，启用集合必须作为一致的整体通过校验。
- 没有契约或全部契约禁用是正常配置，插件完成加载但不注册工作流工具；文件、契约与访问控制管理命令仍可使用。
