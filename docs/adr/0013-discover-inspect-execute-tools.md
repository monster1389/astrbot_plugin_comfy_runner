# 用固定三工具公开工作流发现、查看与执行

替代 ADR-0002。插件不再把每个启用的工作流注册为独立的 AstrBot Function Tool，而是向模型公开 `comfy_list`、`comfy_inspect`、`comfy_execute` 三个固定工具：按需列出可用工作流、查看单个工作流的公开契约、传参执行目标工作流；模型已知目标工作流名称与参数时，可以跳过前两步直接调用 `comfy_execute`。（ADR-0022 在此基础上增加第四个固定工具 `comfy_task` 用于任务管理。）

这样在工作流数量增加时不会把全部参数 Schema 塞进每次模型请求，同时保留每个工作流独立的显式工具契约与严格参数校验。

## 后果

- 固定工具自身的 Schema 与描述保持静态；没有任何启用契约时不注册工具。
- 服务端不维护调用顺序状态，`comfy_execute` 每次独立按目标工作流的契约校验参数。
- `comfy_inspect` 只公开工具契约声明的参数 Schema 与产物类型，不向模型暴露节点 ID、字段名或本地文件路径。
- 内部模块继续抛出异常，最外层工具入口将准入、契约和提交错误转换为文本返回给模型，便于模型自纠或转告用户。
