# 同步校验提交后转入后台等待与交付

替代 ADR-0011。AstrBot 在整轮 Agent 工具循环期间持有会话锁（`session_lock`），若工具调用同步等待 ComfyUI 渲染完成，同一会话在等待期间无法处理任何新消息。因此 `comfy_execute` 在工具调用内同步完成准入、契约参数校验、敏感词检查、并发名额获取、冷却检查以及向 ComfyUI 提交 `/prompt`；取得 `prompt_id` 后立即启动后台任务轮询结果并直接返回已提交状态（含任务 ID），使本轮对话尽快结束并释放会话锁。

## 后果

- 准入拒绝、参数错误、并发已满或 ComfyUI 拒绝提交仍在工具调用内同步返回给模型。
- 并发名额从同步提交前获取，一直持有到后台轮询与按需交付结束后才释放。
- 后台阶段发生轮询超时、节点执行失败或交付失败时，由适配层直接向当前会话发送提示消息；超时按执行状态未知告知用户且不自动重提，可通过 ADR-0022 的 `comfy_task` 自愈查询或补发。
- 插件卸载或重载（`terminate`）时主动取消并回收未完成的后台任务。
