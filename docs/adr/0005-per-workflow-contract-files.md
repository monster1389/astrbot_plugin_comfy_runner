# 工具契约按工作流分文件存储

每个工作流使用一个同名契约文件，例如 `moss.json` 对应 `moss.tool.json`，二者共同存放在插件数据目录的工作流目录中；不把全部契约集中写入 WebUI 的单个大型 JSON 字段。契约按工作流独立编辑、校验和备份，与工具的独立生命周期保持一致。

## 后果

- 第一版直接编辑 JSON；后续管理页面读写同一契约文件，不引入第二套配置源。
- 工作流文件被导入不代表它已经可调用，只有配套契约存在并启用后才注册工具。
- 契约文件属于工作流附属文件，不能作为独立工作流出现在可选列表中。
