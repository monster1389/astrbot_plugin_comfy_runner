# 定位为工作流工具适配器

项目从文生图插件转向 ComfyUI 工作流工具适配器：把用户在 ComfyUI 中设计好的工作流封装为 AstrBot 可调用的工具，由插件负责工具声明、参数映射、执行与结果交付。插件不创建或修改节点图，也不通过注入对话历史或请求上下文让模型理解工作流。

## 后果

- 出图只是工作流执行的一种结果，不再是核心领域抽象；工具契约必须允许工作流声明不同的输入与输出能力。
- 自动绘图、System Prompt 注入和对话历史改写不属于目标架构，移除它们是有意决策而非功能缺失。
- 提示词结构化编辑、标签管理和 LoRA 专用控制不属于执行核心；提示词按普通字符串参数处理，需要公开的 LoRA 能力也走显式工具契约。
- ComfyUI 负责节点图与执行，AstrBot 负责调用与消息承载，插件只通过显式工具契约连接二者。
