# 契约不记录工作流指纹，默认值只来自工作流原值

工作流文件是唯一真源。工具契约只声明对模型公开的接口，既不记录工作流文件的哈希，也不记录参数
默认值。省略某个参数时用的是工作流文件里的原值，`comfy_inspect` 只对可选参数把该原值展示给模型。

不写哈希的理由：工作流里大量未公开的内部参数（步数、CFG、LoRA 权重与开关）几乎每次调优都会变，
而公开映射往往没动，指纹会频繁失效，把「接口没变」误报成「契约过期」；反过来，插件在加载、
`/comfy check` 与每次提交前都会实时读取工作流并把每个映射的节点与字段核对一遍，比指纹更精确地
指出断在哪一条映射上。

不写默认值的理由：契约里再存一份 `default` 就有两处真源，模型看到的默认值可能与不传参时的实际
值不一致，而这种不一致只在生成结果异常时才会被发现。

## 后果

- 可选参数的工作流原值本身必须满足契约声明的类型、枚举与范围，否则契约校验失败、插件拒绝加载。
- 重新从 ComfyUI 导出一份工作流后不需要改契约，只要映射仍然成立。
- 必填参数不展示工作流原值：工作流里留着的测试提示词不会进入模型视野。
