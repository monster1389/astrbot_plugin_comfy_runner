# 每个产物单独发送一条消息

一次执行产生的每个正式产物各自发送一条消息，按自己的消息类型发送：图片用图片段、视频用视频段、
音频用语音段、普通文件用文件段、文本用纯文本，不再把全部产物塞进一条消息链。

QQ 一侧 OneBot v11 把视频、语音、文件当作独立消息段，与文本或图片混在同一条消息链里发送会被
协议端丢弃或让整条消息失败；产物数量可变时，合并也难以确定哪几段该落在同一条里。逐个发送让
每种产物只依赖它自己的消息类型，多图与多产物都按顺序到达。

## 后果

- 一次执行产生 N 个产物，会话里就会出现 N 条消息，不额外发汇总文本。
- 文本产物直接作为消息发送，不落盘，也不与同批次的图片合并。
- 自 ADR-0022 起，文件类产物发送时临时落盘到 `temp/<subfolder>/<filename>`（沿用 ComfyUI 侧路径与文件名），发送成功后即清理，不再在插件侧永久保存；文件类消息名继续沿用原名。
