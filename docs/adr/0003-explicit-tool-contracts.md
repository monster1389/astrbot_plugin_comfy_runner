# 用显式工具契约描述输入与输出

工作流不直接等同于工具；用户为每个工作流定义独立的工具契约，显式声明公开参数及其节点输入映射，以及正式产物及其输出节点映射。节点结构可以由 `/object_info` 辅助读取和校验，但工具语义由用户定义，模型不需要也不能自行猜测节点 ID 或内部连线。

## 后果

- 输入契约包含公开名称、类型、描述、约束和目标 `节点 ID + inputs 字段`；未声明的工作流输入不暴露给模型。
- 输出契约包含正式输出节点与产物类型，并允许一次执行交付多个产物；不得把扫描到的第一张图片视为通用结果。
- 图片、视频、音频与文本可以是不同工作流的正式产物；具体交付能力可以分阶段实现，但契约不以单张图片为中心。
- 中间预览和文本输出不会被自动混作文件，只有声明为正式输出的结果才进入交付流程。
- 所有公开参数和映射在提交前严格校验；节点或字段不存在、目标仍为连线、类型或约束不符、出现未知参数时直接拒绝，不自动修复或忽略。
- 校验错误同时指出公开参数与目标节点字段，配置错误不能留给 ComfyUI 执行后才暴露。
