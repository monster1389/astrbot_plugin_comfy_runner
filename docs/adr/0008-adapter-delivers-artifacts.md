# AstrBot 适配层负责产物交付

工作流工具执行完成后，由 AstrBot 适配层把声明的正式产物交付到当前会话，模型只收到成功或失败的简要结果。模型不接收 ComfyUI 内部 URL 或原始 `history` JSON，也不负责把执行结果转换为聊天消息。

自 ADR-0022 起，仅当模型显式调用 `comfy_task(action="download")` 时才把产物拉取到临时目录并返回本地路径供查看；正常交付与跨工作流串联仍由适配层负责。

## 后果

- 通用执行器提供结构化的执行结果与产物信息，AstrBot 适配层承担消息转换和发送。
- 工具返回值不是二进制产物的传输通道，也不通过暴露内部位置让模型自行请求 ComfyUI。
- 尚未支持的产物类型必须明确报错，不能改用第一张图片或中间预览代替。
