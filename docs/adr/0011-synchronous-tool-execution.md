# 第一版同步等待工具执行结果

工作流工具调用同步等待同一个 `prompt_id`，直到执行成功、明确失败或达到超时边界，再由 AstrBot 适配层交付产物并向模型返回结果。第一版不在提交后立即返回，也不引入后台任务暗中继续等待并主动发消息，使一次工具调用对应一次可理解的执行结果。

## 后果

- 超时结束本次调用，不假装成功，也不在调用结束后暗中补发产物。
- 同步等待只改变调用方式，不改变任务身份；等待期间始终查询同一个 `prompt_id`，禁止盲目重提。
- 后台执行、进度通知和完成后主动消息属于后续独立架构改进，不与第一版混用。
