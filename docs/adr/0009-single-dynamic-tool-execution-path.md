# 不保留新旧两套执行入口

目标架构只通过动态工作流工具执行通用工作流，不长期保留固定文生图命令或“全局当前工作流”对应的旧执行路径。工作流文件管理、契约管理和访问控制命令可以保留，但必须使用新领域模型；迁移可以分阶段完成，但不建立永久双轨兼容层。

## 后果

- 固定文生图、专用步数覆盖和全局工作流切换不再构成另一套参数注入机制。
- 执行器不需要同时维护“当前工作流”和“按工具选择工作流”两种状态。
- 旧能力的保留以能否表达为独立工具契约为准，而不是为了维持命令表面不变而保留旧核心。
- 旧 `bindings`、工作流选择状态和专用 LoRA／步数配置不自动转换，也不与契约文件双读；管理员按新格式手动迁移，插件提供示例与明确错误。
